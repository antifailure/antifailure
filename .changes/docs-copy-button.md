# fixed

The copy button on a terminal code block in the documentation sat outside the
block. Hiding the terminal title bar left Expressive Code still reserving that
bar's height above the button, so on all 116 terminal blocks the button started
40px down a 54px block and hung off the bottom right corner, over the paragraph
beneath, taking the "Copied!" tooltip with it. The install command on the
quickstart was the first one anybody saw.
