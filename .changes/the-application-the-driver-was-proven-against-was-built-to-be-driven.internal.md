# changed

The Electron application the desktop driver is proven against is now an
application somebody would be glad to use.

It was a fixture: a form assembled out of concatenated markup inside a test
file, built to be driven and never to be looked at. It is also the application
a person watches the agent drive, so it had one job and needed two.

It is a macOS window now, in the system's own type, with one palette chosen for
it rather than taken from a framework, one radius vocabulary, one accent that
means something in a ledger, and the unglamorous states that separate an
application from a mock: the signed out ledger with its figures masked, the
refusal that names which field and why, a real disabled control with its reason
stated beside it, and a focus ring a person can see from across a room. Light
and dark are separately authored rather than one inverted into the other, and
every one of the thirty text and background pairs was measured at 4.5 to 1 or
better rather than judged by eye.

Nothing in it animates on a loop, and none of its accessible names changed,
because those names are the interface the driver reads.

Internal, and never published. The application is a test fixture: it is what
the desktop driver is proven against and what a person watches the agent drive
in a film, and a customer's release notes are the wrong place to tell them a
fixture got prettier. changecheck agrees, reporting six changed paths and no
behaviour anybody outside can see, so this is kept for the next person reading
the tree rather than for the changelog.
