# added

The control plane can hold a workload: a named definition, immutable versions of
it, runs of those versions, the measurements a run produced, and the durable
commands that ask a runtime to stop something. Eight tables, each with row-level
security proven from a second tenant by the suite that reads the table list out
of the database.

The four kinds a workload can be, observed load, an HTTP scenario, a browser
workflow and an exploration, stay four kinds. There is no common intermediate
representation behind them, and `workload_run_results` carries a constraint that
refuses a result of one kind wearing another kind's columns.
