# fixed

Five things the product said about itself that the code does not do.

The list of Postgres failures the insights check finds named connection pool
exhaustion. There is no such rule: the catalogue holds seventeen and none of them
concerns pools. The other four in that list are real and stay. The diagram beside
it carried a pool row for the same reason and no longer does.

The pull request gate was described as carrying the video. The runner does record
one, and it never reaches the comment: the report carries the trace.

The egress mode plate showed `api.stripe.com` in `mock`. The mode a detected
Stripe SDK is actually given is `sandbox`, which opens a real connection to
Stripe's own sandbox with a substituted credential, and `mock` is the default for
nothing. On a page about money that is the wrong direction to be wrong in, so the
plate now shows `sandbox`.
