# fixed

The gate that forbids em dashes only ever read Markdown, so the marketing site
and the console had never been scanned once. It reads `.ts`, `.tsx` and `.mjs`
under `www` and `console` too, and finds the character written as an escape or
an HTML entity, which a scan for the character itself cannot see.

Sixty-eight em dashes came off the site as a result. A page's title now joins
its own name to the site's with a middle dot, built and read back in one place
instead of thirty, and where a table has no value it says so in a word rather
than drawing a dash at it. Go-to-market vocabulary that had leaked onto the
public pages, "the migration wedge" and "ideal customer", says what it means.
