# fixed

Four of this repository's own six workflows passed against a page whose every
table had failed to load.

Their expectations named card titles, form labels and words out of the page's
own lede, all of which render whether or not the data arrived. Renaming the
table each page reads out from under it left every expectation satisfied and
the run reported six green over four cards reading "That did not load". Each
workflow now also names something that exists only once the rows rendered, and
each was watched to fail with its own table taken away.
