# changed

Every command now renders through one set of shapes rather than its own. A
heading, a key value block, a status line, a table, a hint and an empty state,
all indented and wrapped the same way, so that the same kind of thing looks the
same wherever it appears.

Two empty states that named no way out of being empty now do: `af inbox list`
says what puts mail in an inbox, and `af secret list` says what puts a value in
the store.
