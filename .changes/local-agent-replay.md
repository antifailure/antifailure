Capture explicit TypeScript agent boundaries locally and save an incident with a verified Postgres golden. Agent replay reproduces the specified original failure before testing a candidate in an independent environment, with strict cassette matching and an inconclusive verdict for missing evidence or unconfirmed cleanup. Saved scenarios can run as local regression suites. The SDK requires explicit content capture and does not provide historical database recovery or a hosted trace store.

Reports omit database row values and primary keys. Retired incident IDs cannot be imported again. Replay checks the proxy's independent writer status and admitted work against its retained log, including failures writing the final record.
