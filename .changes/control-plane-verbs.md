# added

The hosted console can act, not only report. An egress rule now waits for
approval instead of enforcing the moment a member proposes it, and the console
carries the queue and the approve control. Create environment, Run agents and
Run load dispatch your own workflow in your own repository, so the work still
happens in your CI and your data stays there; they need the GitHub App to have
Actions write. Runtimes can be registered, tagged and removed, and the registry
now shows what environments are actually running on beside what somebody
registered. The plan can be read and set, which is what the quota enforcement
has always needed and never had. Setting the plan takes no payment.
