# changed

The question after the first sign-in has become a short walk beside the
cover pane you signed in through.

The one question asked which of three people you were and showed that one's
next step. Somebody who wanted checks on pull requests and a terminal on the
same machine had to pick one and lose the other's instructions. The plan was
a page found later or never, so the first time most people met a limit was
the refusal. And nothing said what the control plane was for once something
had been connected, so the environments list stayed the explanation.

The console now walks four steps, one screen at a time, in the column the
sign-in button was in, with the sign-in cover beside it. Where you will use
Antifailure, ticking every place that applies. Which plan to start on, with
the limits each one enforces, read from the control plane's own tables, and
the plain fact of whether this control plane takes payment at all, whether
you may buy on the organization's behalf, and whether the plan is bought here
or arranged with a person. One setup card per place you ticked, with the App
install and a live line saying how many repositories it reached and what the
App did about each one's workflow, the three terminal commands addressed to
this control plane, or the agent endpoint and what a credential on it may do,
each with a Done you can mark and none of them blocking. Then four things the
control plane gives you, each from the documentation, and the way out: the
environments list, or Stripe's checkout when a paid plan was chosen, which
opens only now, after setup, so nobody pays before anything is connected.

The one word the console remembered before is still the word it remembers,
so the root, Settings and an older console keep reading it. Skip for now and
Escape still land on the environments list and are not asked again.
