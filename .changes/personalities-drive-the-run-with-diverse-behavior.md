# added

A change can be exercised by a population of personalities, not one scripted
path.

A workflow declares a goal, and until now one agent pursued it one way. A
regression that only a different kind of user provokes, the one who reads every
label before acting, the one who takes the first prominent control and never
scrolls, the one who probes the unusual path, went unseen, because the single
agent never behaved like them. A single path through the twin is a single
opinion about how the change behaves.

A new top level `diversity` block turns on a population. It draws agents from a
built in catalogue of ten personalities, each a behavioral lens ported from a
diversity model: an explorer, a fast actor, a cautious analyst, a skeptic, an
edge case prober, and five more. A personality is HOW an agent behaves, kept
deliberately separate from the persona it signs in as, which is WHO it is: a
personality reaches no provisioning and changes only which of the controls
already on the page an agent prefers and how it explains the choice. It can
never name a control that is not there, because the action grammar and the
exact name refusal below the personality preamble are untouched.

The whole plan is resolved from a seed: the same seed against the same
application assigns the same personalities and the same behavioral profiles,
step for step, so a personality driven finding replays the way an exploration
does. Because each personality's reasoning is part of the model prompt and the
cassette keys on the whole prompt, N personalities over one page record N
answers and the pipeline stays exactly reproducible and free to replay, with a
missing recording blocking loudly rather than reaching the network. Off by
default: a manifest with no `diversity` block, or one that is disabled, runs
exactly one neutral agent per workflow as before.

The personalities run through the same key the runner already reads from the
environment, the user's own, on the ungated model path. Nothing here gates them
behind an edition, and a test refuses the import that would.
