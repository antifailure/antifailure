The first golden is a `pg_dump` piped into `pg_restore`. A branch is `CREATE DATABASE ... TEMPLATE`, which copies files, so branch time grows with the database. It is not flat and this provider does not claim it is.

Read the per gigabyte column from the LARGEST row. A small database is mostly fixed cost, the empty template Postgres copies whichever database you asked for, so dividing a few seconds by a few megabytes produces a rate that is real for nothing. The rate the larger rows agree on is the one that carries.
