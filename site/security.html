→Fail closed

Designed denies. Unknown, unresolved, or uncontained is a block — not a warning you can click through.

  • Unknown outbound destination

    No default public egress. Unknown destinations are blocked and written to the attempted-effect ledger.

    BLOCK

  • Unresolved secrets

    Missing or production-scoped credentials cannot be replaced with twin identity. The run does not start.

    BLOCK

  • Incomplete cleanup policy

    No TTL, no cost ceiling, or no independent teardown path. Convenience does not override containment.

    BLOCK

  • Missing isolation

    No dedicated account, project, or strongly isolated network when the risk requires it. The run is blocked.

    BLOCK

  • Direct-IP or production hostname

    Bypass attempts and production API hosts are denied by default and flagged as critical.

    BLOCK

  • Failed cleanup

    If destruction cannot be proven, the run fails. Orphans are not a background inconvenience.

    BLOCK

Cleanup is a safety property, not a best-effort script.

Every environment has a TTL, a hard cost ceiling, an independent reaper, and a verifiable destruction record. Resource tags carry the run ID and expiration. Failed teardown fails the run.

What we will not claim
Open source does not bypass compliance. Inspectability of the data plane is not a substitute for customer-managed keys, residency, audit, or a published threat model. Safety is not an enterprise add-on — the open product must still be safe.
