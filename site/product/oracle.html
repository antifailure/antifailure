Expected differences
Intended product changes are declared so they do not appear as false regressions. A new access_tier field in JSON is allowed. A duplicate Stripe charge is not.

The durable layer is the decision. Understand, reproduce, compare, attribute, recommend.

  • HTTP

    Normalized responses, status codes, and error classes.

  • Data

    Database writes, events, and queue emissions.

  • Effects

    Third-party effects captured by the firewall ledger.

  • Runtime

    Trace topology, query count and plans, latency, resources.

  • Journeys

    User-journey outcomes, logs, and exceptions.
